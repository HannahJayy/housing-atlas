# Housing Atlas

Free housing-market maps, rankings and reports, built from Zillow, Redfin, Realtor.com, Census, BLS, BEA, FRED and FHFA data.

**Your site:** `https://YOUR-GITHUB-USERNAME.github.io/housing-atlas/`. Use your own username. If you named the repository something else, use that name instead of `housing-atlas`.

- **Weekly refresh:** every Sunday, GitHub downloads the newest data and republishes the site. Nothing needs to be running on your computer.
- **Refresh now:** go to **Actions**, then **Publish Housing Atlas**, then **Run workflow**. It takes about 30 to 45 minutes.
- **Your watchlist and saved map views** are kept in each phone's or computer's browser.
- **Where the numbers come from:** see [SOURCES.md](SOURCES.md) or the Data & Sources page on the site.

This web copy is read-only. The version you run on your own computer (`python app.py`) also has accounts, settings and an Update button.
